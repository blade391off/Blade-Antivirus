# Contributing to Blade-Antivirus

Thank you for your interest in contributing to **Blade-Antivirus**! To maintain code quality, efficiency, and compliance, all contributors must strictly adhere to the following guidelines.

## 🚫 Eligibility & Compliance Restrictions

Due to compliance, international sanctions, and the specific security policy of this repository, we **do not accept** code contributions, pull requests, bug reports, or forks from individuals or entities located in or affiliated with the following countries:
* **Belarus**
* **Russian Federation**

By submitting a Pull Request, you officially certify that you are not operating from, located in, or a citizen of these restricted regions. Submissions originating from these jurisdictions will be rejected and blocked immediately.

## 🛠️ Technical Requirements

Blade-Antivirus is written in native C++ and is engineered for absolute performance and zero background overhead. We do not accept bloated code or modern AI dependencies.

To contribute, you must meet the following **minimum technical criteria**:
1. **Modern C++ Knowledge:** You must possess at least strong intermediate C++ skills (understanding of modern standards like C++17/C++20, memory management, pointers, and RAII).
2. **Zero Bloat Policy:** No external third-party heavy frameworks. Keep the codebase lightweight and highly efficient.
3. **No Background Code:** Any code introducing persistent background daemons, agents, or automated stealth processes will be strictly rejected.
4. **Code Quality:** Ensure your code is properly formatted, follows standard naming conventions, and contains zero memory leaks.
