# Security Policy

## Supported Versions

We actively support and patch security vulnerabilities only in the latest open-source releases of **Blade-Antivirus**. If you are using an older build, please upgrade to the latest version before reporting an issue.

| Version | Supported |
| ------- | --------- |
| Latest  | ✅ Yes     |
| < Latest| ❌ No      |

## Reporting a Vulnerability

As a security tool engineered in native C++, we take code safety, memory management, and potential exploits extremely seriously. 

**Please do not open a public GitHub Issue for security vulnerabilities.**

If you discover a vulnerability, memory leak, or potential bypass in Blade-Antivirus, please follow these steps:
1. Send a detailed report via email to **bladeyep@gmail.com**.
2. Include a description of the vulnerability, a proof of concept (PoC), and steps to reproduce the issue.
3. If applicable, specify the operating system and compiler options used.
