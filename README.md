# Blade-Antivirus

Blade-Antivirus is an on-demand malware detection utility compiled in native C++ for direct hardware execution and system analysis. 

The software architecture is engineered to exclude background persistence, system daemons, and speculative analysis models. Blade-Antivirus operates strictly upon manual initialization by the user, maintaining a zero-resource footprint during passive states and ensuring complete user allocation of central processing and volatile memory resources.
